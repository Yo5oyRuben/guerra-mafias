# Scripts utiles

Esta carpeta contiene solo los scripts necesarios para compilar el codigo C y regenerar las figuras principales.

- `build_c.ps1`: compila los ejecutables principales del modelo.
- `build_paper.ps1`: atajo para compilar el modelo de `c_paper`.
- `run_initial_plane_parallel.ps1`: compila y ejecuta un barrido de condiciones iniciales.
- `regenerate_initial_plane_time_plots.ps1`: regenera graficas de planos iniciales con tiempo de relajacion.
- `regenerate_all_initial_plane_new_style.ps1`: regenera en lote las graficas de planos iniciales con el estilo final.

Los scripts usados solo para lanzar colas largas de simulaciones se han eliminado para mantener el repositorio limpio.
