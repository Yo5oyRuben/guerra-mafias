# Aplicaciones y experimentos numéricos

Esta carpeta contiene distintos programas ejecutables usados para realizar los experimentos. Los experimentos que hemos realizado podrían clasificarse en 2 grupos. Primero, hemos realizado diferentes barridos en el parámetro b para diversos conjuntos de valores del resto de parámetros (carpeta de sweep_b). Luego, para verificar la robustez de nuestro programa, hemos lanzado simulaciones en el limite termodinamico y/o de altas conectividades (carpeta de well_mixed_limit), comprobando bajo estas condiciones la dinámica ante diferentes probabilidades de copia. También hemos estudiado la transición entre regímenes donde la dinámica microscópica se desvía de las predicciones analíticas y aquellos en los que el comportamiento macroscópico converge hacia el descrito por las ecuaciones de campo medio.
