# Resultados y datos de simulación

Esta carpeta contiene los datos generados por las simulaciones.
Los experimentos concretos realizados de forma organizada se encuentran en la carpeta `experiments/`. 

La carpeta `gp/` contiene scripts de `gnuplot`.

El resto de carpetas presentes en `out/` son utilizadas por los distintos programas para depositar archivos de salida. Los resultados relevantes obtenidos durante el desarrollo del proyecto han sido reorganizados dentro de `experiments/`.

Para una descripción más detallada de los experimentos realizados y de la organización de los resultados, consultar la carpeta `experiments/`.
